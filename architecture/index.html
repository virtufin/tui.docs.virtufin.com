    Components¶

    1. App (src/virtufin_tui/app.py)¶

    The root App subclass. Holds a single TuiConfig, connects to the active context, and pushes the Dashboard dispatcher. Global keybindings: q quit, ? help, 1/2/3 switch page.

    2. Dashboard dispatcher (src/virtufin_tui/screens/dashboard.py)¶

    A thin Screen wrapper. Owns the DataPump (poller + subscriber) and routes the 1/2/3/4 keybindings to the matching per-page Screen. Page state is remembered across context switches.

    3. Data store (src/virtufin_tui/store.py)¶

    Three reactive containers populated by the DataPump:

    Store Source Refresh
    WorkersStore client.list_workers() 2 s polling
    ConnsStore client.list_connections() 2 s polling
    EventsStore Gateway.Subscribe server-streaming Push, unbounded → bounded via append, max 500 entries

    Per-page Screens subscribe to their store and re-render on each update. The DataPump survives page switches; hot context switching stops the old pump, re-creates the gRPC channel, and starts a fresh pump.

    4. Config loader (src/virtufin_tui/config.py)¶

    Reads contexts.toml from ~/.config/virtufin-tui/ (XDG-aware via $XDG_CONFIG_HOME). Applies VIRTUFIN_TUI_API_HOST/VIRTUFIN_TUI_API_PORT/ VIRTUFIN_TUI_CONTEXT env-var overrides. Returns a TuiConfig with the list of contexts and the active one.

    5. Client wrapper (src/virtufin_tui/client.py)¶

    Thin async wrapper around virtufin.api.client.ApiClient that exposes the operations the TUI needs as plain async methods (no Textual dependencies). This is what the pages call for CRUD (set-tag, start, stop, delete, etc.).

    6. Per-page Screens (src/virtufin_tui/screens/*.py)¶

    Screen File Keybindings
    Workers page (1) workers_page.py r refresh, Enter detail, a action modal
    Events page (2) events_page.py space pause/resume, c clear, / filter
    Connections page (3) connections_page.py r refresh, Enter detail, a action modal
    Scripts page (4) scripts_page.py r run, s save, n new, arrow keys navigate
    Contexts picker contexts_picker.py Push via c

    All per-page Screens are Screen subclasses (not modals). Detail popovers (WorkerDetail, ConnectionDetail) and the action modal are pushed on top of the active page. The service browser is pushed via b.

    Real-time updates¶

    The TUI uses two real-time paths, both running inside the DataPump at the Dashboard level:

    1. Polling (state lists) — ListWorkers and ListConnections every 2 s (configurable). Each poll writes into WorkersStore / ConnsStore, which triggers a re-render in the active per-page Screen.

    2. Streaming (events) — Gateway.Subscribe(services, topics, event_types) is opened once at context connect and consumed in a background task. Events append to the EventsStore (bounded deque, max 500 entries). The Events page subscribes to the store and re-renders the RichLog on each append.

    On context switch (c → picker), the old DataPump is stopped cleanly, the gRPC channel is replaced, and a new DataPump is started.

    Cancellation / reconnect¶

    gRPC channels are wrapped in grpc.aio.insecure_channel (or secure_channel if tls: true). The subscriber task retries with exponential backoff (1s, 2s, 4s, 8s, 16s, 30s cap) on disconnect. Events are queued in the EventsStore and are not replayed on reconnect. The store persists across page switches and is cleared only on context switch.

    Lifecycle¶

    1. virtufin-tui is invoked (from uvx, pip install, or local).
    2. app.main() parses --config and --context flags.
    3. config.load_config() reads contexts.toml and applies env-var overrides.
    4. If no contexts configured, the TUI opens the contexts picker and prompts the user to add one. On save, the TUI restarts with the new active context.
    5. Otherwise, VirtufinTuiApp.on_mount() creates a TuiClient, connects to the API, pushes the Dashboard dispatcher, and starts the DataPump.
    6. The Dashboard pushes the default page (WorkersPage) via push_screen. Keybindings 1/2/3 switch pages.
    7. On q (quit), the TUI cancels background tasks, closes the gRPC channel, and exits 0.
